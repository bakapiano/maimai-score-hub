# 拍照识曲前端交互

## 首期入口

首期不增加新的一级导航。在 `/app/scores` 的“全部成绩”搜索框旁增加相机按钮：

- 移动端：相机按钮与搜索框同一行，点击后打开底部抽屉。
- 桌面端：同一按钮打开文件选择/识别弹窗。
- 离线模式：按钮禁用并说明“拍照识曲需要联网”。

以后如果识曲扩展为独立曲库浏览、成绩图解析或批量工具，再增加 `/app/recognize` 页面。

## 入口流程

```text
点击相机
  → 选择“拍封面”或“拍曲名”
  → 拍照 / 从相册选择
  → 裁剪并预览
  → 上传识别
  → 展示最多 3 个候选
  → 用户选择候选
  → 按 musicIds[] 筛选全部成绩
```

首期使用明确模式，不让模型自动猜用户是在拍封面还是曲名。模式决定取景框比例、提示文案和服务端 pipeline。

## 拍封面

- 显示方形取景框。
- 提示“让封面尽量填满方框，避免反光和倾斜”。
- 允许拍照后拖动、缩放 crop。
- 上传前展示裁剪后的最终区域，而不是只展示整张原图。

## 拍曲名

- 显示横向取景框，建议宽高比约 4:1 到 7:1，最终范围由数据验证。
- 提示“只框住完整曲名，尽量不要包含难度、等级和其他按钮”。
- 保留特殊字符和日文，不对图片做二值化等破坏艺术字的前端处理。
- 结果区可以显示 OCR 原文，但用户最终选择的是曲库候选。

## 相机实现

首版优先使用浏览器原生文件输入：

```html
<input type="file" accept="image/jpeg,image/png,image/webp" capture="environment" />
```

同时提供“从相册选择”。原生 capture 的设备兼容性优于首版自行维护完整相机页面。

当需要实时取景框、连续拍摄或自动清晰度检测时，再使用 `getUserMedia`。无论采用哪种方式，都必须保留文件选择 fallback。

前端可以使用 canvas 做预览和带宽优化，但服务端仍必须独立验证：

- 应用浏览器可见方向。
- 最长边压缩到约 1600 px。
- JPEG quality 首期可从 0.82 开始。
- 不把 data URL 写入 localStorage、日志或错误上报。

HEIC/HEIF 不列入首期显式支持格式。若 Safari 能在浏览器解码并经 canvas 转为 JPEG，可以正常上传；否则提示用户使用相机直接拍摄或转成 JPEG。

## 请求状态

前端状态机：

```text
idle
  → selecting
  → cropping
  → uploading
  → result | no_match | error
```

要求：

- `uploading` 时允许取消当前请求。
- 组件卸载或用户重新选图时使用 `AbortController` 取消旧请求。
- 同一界面不并发提交多张图。
- 超时、服务繁忙、无法识别使用不同文案。
- `503/429` 尊重 `Retry-After`，倒计时结束前禁用重复点击。

## 候选展示

结果抽屉最多显示 3 张候选卡：

- 标准封面。
- canonical title。
- SD/DX 类型；同标题多 ID 时同时展示。
- 简短信号说明，例如“封面匹配”“曲名与 OCR 一致”。
- top-1 在 `confident` 时高亮，但不自动跳转或写入成绩。

用户点击候选后：

1. 将 `musicIds[]` 作为结构化过滤条件应用到“全部成绩”。
2. 搜索框显示标题，但筛选逻辑不能只做 title substring。
3. 如果用户没有该曲成绩，仍显示“已识别为 …，你的成绩中暂无该曲”，而不是让空列表看起来像识别失败。
4. 用户可以返回候选、重新裁剪或换另一种模式。

## 失败文案

| 场景 | 建议文案 |
| --- | --- |
| `no_match` | 未识别出乐曲，请让目标区域填满取景框后重试 |
| `ocr_busy` | 识别服务繁忙，请稍后重试 |
| `ocr_timeout` | 识别超时，请检查网络后重试 |
| `unsupported_image_type` | 暂不支持该图片格式，请使用 JPG、PNG 或 WebP |
| crop 无效 | 裁剪区域过小，请重新框选封面或完整曲名 |
| 离线 | 当前为离线模式，拍照识曲需要联网 |

## 纠错反馈

首期至少记录用户是否选择了非 top-1 候选。后续可增加“都不是”入口：

- 默认只上传 request id、候选、用户最终选择和版本信息。
- 原图只有在用户明确同意用于改进识别时才保留。
- 反馈不能修改用户成绩，只用于评估和训练数据筛选。
