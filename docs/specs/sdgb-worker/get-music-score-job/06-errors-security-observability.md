# 错误、安全与可观测性

[← 返回总览](./README.md)

## 1. 用户可见错误

| errorCode | 用户含义 | 建议操作 |
| --- | --- | --- |
| QR_INPUT_REQUIRED | 未提供二维码 | 重新输入或选图 |
| QR_IMAGE_DECODE_FAILED | 图片中未识别到二维码 | 更换清晰图片 |
| QR_EXPIRED | 二维码已失效 | 获取新二维码 |
| CABINET_NOT_BOUND | 账号尚未绑定 | 先完成绑定 |
| CABINET_USER_MISMATCH | 二维码与绑定账号不一致 | 使用当前绑定账号的二维码 |
| SYNC_IN_PROGRESS | 已有手动同步进行中 | 等待当前任务结束 |
| ACCOUNT_ALREADY_LOGGED_IN | 账号当前不可用于本次更新 | 结束当前使用后重试 |
| SESSION_CLEANUP_PENDING | 上一次临时状态仍在清理 | 等待并继续轮询 |
| SESSION_CLEANUP_UNCONFIRMED | 暂时无法确认已安全结束 | 按 retryAfter 重试 |
| WORKER_INTERRUPTED_SESSION_CLEANED | Worker 中断但已安全清理 | 使用新二维码重试 |
| NO_SCORE_DATA | 未读取到可用成绩 | 检查账号后重试 |
| SYNC_PERSIST_FAILED | 成绩保存失败 | 稍后重试 |
| CABINET_SCORE_JOB_FAILED | 未分类的安全错误 | 稍后重试或联系管理员 |

用户文案不得包含机台侧服务信息、内部异常栈或 worker 实现细节。

## 2. 认证与授权

- 所有 /me/cabinet-score-jobs 接口使用用户 JWT。
- backend 只信任 JWT 中的用户身份。
- 客户端不能指定 owner、好友码或绑定账号。
- 查询指定任务时校验 owner，不属于当前用户时返回 404。
- 浏览器不能访问 worker 内部任务接口。
- worker 与 backend 的内部认证属于部署边界，不在公开 spec 中记录。

## 3. 数据保护

- 二维码按一次性敏感凭据处理。
- 图片只在当前 HTTP 请求内存在。
- 二维码和临时会话信息不得进入普通日志、用户响应、Admin 列表或分析平台。
- 原始成绩快照只用于一次 finalization，不在任务集合重复保存。
- 终态后清除任务中的敏感输入。
- 运行时秘密只通过受控部署环境提供，不写入 Git、镜像层、文档或日志。
- 任何恢复记录都必须最小化、短时、受保护，并在清理成功后失效。

本文不得记录具体保护算法、秘密格式、派生规则或轮换操作。

## 4. 日志

允许记录：

- jobId、worker 实例的非敏感标识；
- status、stage、cleanupStatus；
- 稳定 errorCode；
- 安全的数量、耗时和重试次数；
- backend finalization 是否成功。

禁止记录：

- 二维码、图片、绑定账号标识；
- 临时会话凭据或恢复记录内容；
- 机台侧地址、完整请求、完整响应；
- 原始成绩列表；
- 内部认证信息；
- 可还原 worker 私有协议的调试数据。

错误对象进入日志前必须经过显式脱敏，不能依赖默认序列化。

## 5. Metrics

至少监控：

- get_music_score 各状态和阶段的任务数；
- 创建到开始、开始到终态的耗时；
- 成功、业务失败和清理失败率；
- cleanup pending / unconfirmed 的数量与持续时间；
- 中断恢复次数与结果；
- 二维码过期、账号不匹配、无成绩和持久化失败计数；
- 成功写入的成绩数量分布；
- 用户等待时间和任务积压。

指标 label 必须低基数，不能包含二维码、账号标识或完整错误文本。

## 6. Admin 视图

Admin 可以查看：

- 任务类型、状态、阶段和清理状态；
- 创建、开始、完成时间；
- 脱敏错误码；
- 结果摘要；
- worker 健康和队列积压。

Admin 不得查看：

- 任务原始 payload；
- 二维码、绑定账号标识和临时凭据；
- 原始成绩快照；
- 私有恢复记录；
- 机台侧请求、响应或服务地址；
- sdgb-worker 源码实现信息。

## 7. 安全失败原则

- 无法确认身份时，不进入成绩读取。
- 无法保证安全收尾时，不开始或不继续敏感阶段。
- 无法确认 cleanup 成功时，不写 sync。
- 无法校验结果归属时，不写 sync。
- 无法安全展示错误时，使用通用错误码。
- 监控或日志失败不能导致敏感数据回退到未脱敏通道。

- 机台侧域名、IP、路径和接口名；
