## 1. 功能摘要

- 同步页支持 DX Net Bot 和二维码两种手动更新方式。
- 二维码方式接受当前有效的二维码字符串或二维码图片。
- 图片仅在 backend 当前请求中解码，不作为文件进入任务队列或持久化存储。
- 二维码方式只对已绑定机台账号的登录用户开放。
- backend 从登录身份取得任务 owner，不接受客户端指定其他用户或绑定账号。
- 内部任务类型为 get_music_score，与现有 DXNet job 分开管理。
- sdgb-worker 验证二维码归属并生成一次成绩快照；机台侧交互属于私有实现。
- 临时登录状态必须安全结束。结束状态未确认时，不写入成绩，也不允许同一用户创建新的二维码成绩任务。
- backend 将成绩快照映射到现有 sync 数据，成功后可沿用现有自动导出能力。
- 用户、Frontend、Admin 和普通日志只能看到脱敏后的任务状态与结果摘要。

## 2. 用户流程

1. 用户在同步页选择“二维码”。
2. 用户粘贴新二维码字符串，或上传包含二维码的图片。
3. backend 校验登录身份、账号绑定和任务互斥，创建任务并返回 202。
4. Frontend 轮询脱敏后的任务状态。
5. sdgb-worker 在内部安全边界内处理二维码并生成成绩快照。
6. backend 校验任务归属和结果，写入最新 sync。
7. Frontend 刷新最新成绩；如用户已配置查分器导出，则异步触发导出。

## 3. 数据边界

| 数据 | 允许出现的位置 | 禁止出现的位置 |
| --- | --- | --- |
| 二维码字符串 | 当前请求、受控内部任务、任务执行期内存 | 用户响应、URL、浏览器存储、分析事件、普通日志 |
| 二维码图片 | 当前上传请求 | 数据库、队列、worker、对象存储、日志 |
| 绑定账号标识 | backend 私有校验边界 | 用户任务响应、Frontend 状态、普通日志 |
| 临时会话凭据 | worker 私有运行边界及受保护的短期恢复记录 | Git、任务公开视图、Admin 列表、普通日志 |
| 原始成绩快照 | worker 到 backend 的受控内部传输 | 用户任务响应、长期任务结果、普通日志 |
| 结果摘要 | backend、用户任务响应 | 不适用 |

任务成功后，长期保留的业务结果只有 sync 引用、成绩数量和必要的审计状态。二维码、临时凭据和原始成绩副本应尽快清除。

## 4. 范围

本功能包含：

- 字符串和图片两种二维码输入；
- 登录用户的创建、活动任务查询和单任务查询；
- 跨 DXNet/二维码方式的手动同步互斥；
- 任务状态、进度、清理状态和安全错误提示；
- 成绩映射、sync 写入和可选自动导出；
- 中断恢复、清理阻塞、脱敏、监控和回归测试。

本功能不包含：

- 保存历史二维码供后续复用；
- 允许未绑定账号通过二维码更新；
- 浏览器直接调用机台侧服务；
- 公开 sdgb-worker 私有协议或源码实现；
- 替换现有自动更新策略；
- 修改机台侧成绩；
- 浏览器直接调用摄像头扫码。
